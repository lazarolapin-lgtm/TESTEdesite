📌 Sobre o ARCH.

Aplicativo web para conversão e organização de documentos. Os arquivos selecionados são processados no navegador. Esta versão não envia documentos para servidores.

Formatos: PDF → PNG; Word DOCX → PNG; edição de texto próprio; exportação de informações para PDF e DOCX. Arquivos Word antigos (.doc) precisam ser salvos primeiro como .docx.
